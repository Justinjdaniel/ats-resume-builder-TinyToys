# Developer & AI Agent Instructions — ATS Resumaster

This document provides technical guidelines and architectural context for AI coding assistants and developers working on the ATS Resumaster codebase.

---

## Workspace Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Modern Vanilla CSS Design System (`src/index.css`) with custom glassmorphism components & print media rules
- **Testing**: Vitest + React Testing Library + JSDOM (`npm run test`)
- **File Parsing**: `mammoth` (DOCX), `pdfjs-dist` (PDF), native FileReader (MD, JSON, TXT)
- **Document Generation**: `docx` (Word .docx), `html2pdf.js` / browser print vector fallback (PDF)
- **State Management**: React local state + `sessionStorage` for BYOK configuration

---

## Architectural Principles & Rules

1. **Bring Your Own Key (BYOK) Session Privacy**:
   - API keys are saved strictly in browser `sessionStorage` (`ats_resume_builder_byok`).
   - Keys MUST NOT be logged, stored in `localStorage`, or sent to any backend server. All LLM calls are client-to-provider directly.
   - Always preserve the heuristic offline fallback (`runHeuristicOptimization`) so users can test without entering an API key.

2. **ATS Output Integrity**:
   - Resumes generated by templates or exported to DOCX/PDF MUST use standard ATS section headings (`WORK EXPERIENCE`, `CORE COMPETENCIES`, `EDUCATION`, `PROJECTS`, `CERTIFICATIONS`).
   - Bullet points MUST start with strong action verbs and incorporate quantifiable metrics.

3. **Template System**:
   - Layout templates reside in `src/templates/`.
   - Each template accepts `{ data: ResumeData, config: LayoutConfig }`.
   - To add a new template, create a component in `src/templates/`, register its ID in `src/templates/types.ts`, and add it to `TemplateSelector.tsx` and `ResumeEditorPreview.tsx`.

4. **Testing Policy**:
   - **MANDATORY**: Always run `npm run test` and `npm run build` after making code changes.
   - Never remove existing tests; add unit tests for new parser utilities or template logic in `src/test/`.
